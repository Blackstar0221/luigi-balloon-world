# 🎈 루이지 풍선월드 (Luigi Balloon World)

마리오 오디세이풍 2D 왕국에서 풍선을 **숨기고 찾는** 싱글플레이 웹 게임입니다.
별도 설치·서버·의존성 없이 **`index.html` 하나**로 동작합니다 (순수 HTML/CSS/Canvas).

## ▶ 플레이 방법

`index.html` 파일을 브라우저로 열기만 하면 됩니다.

또는 로컬 서버로:

```bash
python -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 🎮 조작

| 동작 | 키보드 | 터치 |
|---|---|---|
| 이동 | `←` `→` / `A` `D` | 왼쪽 화면 드래그 |
| 점프 | `Space` · `↑` · `W` | 점프 버튼 |
| 액션(숨기기·터트리기) | `↓` 아래 방향키 | 액션 버튼 |
| 사다리 오르기 / 내리기 | `↑` / `S` | 드래그 위·아래 |

## 📜 규칙

- 시작 코인 **500개**.
- **🎈 숨기기 (무료, 1개):** 숨길 곳에 내 풍선을 배치한다. 봇들이 시간이 지나면 찾아내고, 그때마다 코인을 준다. 내 **랭크가 높을수록** 보상이 커진다.
- **🔍 찾기:** 먼저 풍선을 고르고 **200코인 선불** → **30초 타이머** 안에 그 풍선까지 가서 터트리면 보상 획득. 시간 안에 못 터트리면 선불 코인을 잃는다.
- **보상 = 기본값 × 숨긴 봇 랭크배수 × 난이도배수.** 높은 랭크·어려운 위치일수록 비싸다.
- 많이 찾을수록 **랭크 상승** (브론즈 → 실버 → 골드 → 플래티넘 → 다이아) → 내가 숨긴 풍선의 값도 비싸진다.

## 🗺️ 월드

- 가로로 아주 넓은(≈5600px) 수직 왕국. 점프로 오르는 다층 발판, 사다리, 성, NPC, 동쪽 확장 언덕, 하늘 높이 솟은 첨탑.
- 30곳의 숨길 곳(덤불·항아리·상자, 난이도 1~5)에 봇 풍선 20개가 흩어져 있다.

## 🤖 멀티플레이에 대하여

"다른 플레이어"는 실제 온라인이 아니라 **AI 봇 시뮬레이션**입니다. 상시 서버·호스팅 비용 없이 즉시 플레이할 수 있도록 한 선택입니다. 진행 상황(코인·랭크)은 브라우저 `localStorage`에 저장됩니다.

## 🛠️ 기술

- 단일 HTML 파일, 외부 의존성 없음
- 2D Canvas 렌더링, `requestAnimationFrame` 게임 루프
- 키보드 + 터치(드래그 조이스틱/버튼) 동시 지원
